# 阶段边界

**阶段（phase）** 是会话内的一块工作：访谈、实现、QA。这个定义故意是模糊的：当你心里冒出 *"ok，那块搞完了"* 的时候，阶段就结束了。

**阶段边界（phase boundary）** 是两块阶段之间的空隙，而这类决策只属于这一个地方。阶段进行到一半时并不存在决策可做：要么继续，要么把剩下的工作拆成子 agent。阶段进行到一半时做 compact，会让 agent 丢掉脉络。

## 五个选项

| 选项            | 它做什么                                                            |
| --------------- | ------------------------------------------------------------------- |
| **Continue**    | 留在本会话。完全不做上下文切换。                                    |
| **`/clear`**    | 清空上下文窗口，从零开始。                                          |
| **`/handoff`**  | 写出一份可移植的 markdown 文件，并在任意位置用其作为种子开启新会话。 |
| **Subagent**    | 把任务送到自己的上下文窗口里，拿一份报告回来。                      |
| **`/compact`**  | 压缩当前上下文，并把这份摘要作为种子开启新会话。                    |

## 决策树

在边界处从上到下走。第一个 **yes** 胜出。

**1. 你能在本会话里继续吗？**两个条件会让答案是 yes：下一阶段需要把本阶段当作 **主源（primary source）**，或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone) 足够（约 150k token），下一阶段能塞得下。Grilling → 实现是标准的 yes：实现想要那段推理的原文，而不是它的摘要。Continue 不花钱也不丢东西，所以先把它排除。

**2. 上下文对接下来的事无关吗？**这场会话里的一切（探索、决策、死胡同）是不是都可以丢掉？如果是，`/clear`。它是棋盘上最便宜的一步：不需要时间，把整张窗口都还回来。`/clear` 也不是终态：旧会话依然可以恢复。

判断错误的代价是单向的：清掉了一份**相关**的上下文，你就丢了为什么这么做的**为什么**，再怎么把 diff 读回来也拿不回去。

**3. 你需要交接吗？**`/handoff` 范围很窄。只在以下情况才需要它：

- 切到**新的 harness**（Claude → Codex），
- 转到**新的目录**或仓库，
- 把工作交给**同事**，
- 或者在**阶段中途**发现一项旁支任务，想把它叉出去而不打断手头的工作。

那张列表就是整个条款。`/handoff` 换来的是**可移植性**：一份可以搬走的文件。如果没有什么在搬，你就不需要它。

**4. 这件事能 AFK 跑完吗？**它范围紧凑到你离开键盘、不需要引导就能跑完吗？如果是，送给一个**子 agent**，本会话不动。自动评审就是标准案例：agent 读 diff 并报告，它做的过程中你并不在场。

**5. 否则，`/compact`。**上下文相关、同一 harness、同一目录，而且你需要留在回路里：决策树落在这里，并且常常落在这里。给它一条指令（`/compact we're going to QA this area`），让摘要保留下一阶段需要的东西。

`/compact` 是**默认值，不是第一反应**。它落在最底部，因为它上面那四道题都更便宜或更精确。人们一上来就伸手够它时的失败模式是：一个新会话对自己被摘要压平的某项决策"自信地错了"。

## 主源与第二手源

除 **Continue** 之外的每一个动作，都把一份**主源**变成一份**第二手源**：原本的会话被替换为它的摘要。取舍永远是同一个形状：

| 源                                          | 信息量 | 噪声 | 腾挪空间 |
| ------------------------------------------- | ------ | ---- | -------- |
| 主源（Continue）                            | 完整   | 多   | 少       |
| 第二手（`/compact`、`/handoff`）            | 有损   | 少   | 多       |

这就是为什么问题 1 排第一。只有当"留下来"的代价高于它节省的代价时，你才为这种"有损"买单。

## 这些都是判断题

这些问题不是客观的：每一道都带偏好，同一条边界在不同的日子可能走两个方向。价值在于**按顺序**问 —— 在边界处，而不是在工作进行到一半时问。
