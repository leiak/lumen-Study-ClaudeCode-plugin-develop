# Triage Labels

这些 skill 使用五个规范化 triage 角色来沟通。此文件将这些角色映射到此仓库的 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue  |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 完全指定，准备好交给 AFK agent  |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现            |
| `wontfix`                  | `wontfix`            | 将不会被处理                     |

当 skill 提到一个角色时（例如 "apply the AFK-ready triage label"），使用此表中相应的标签字符串。

编辑右列以匹配你实际使用的任何词汇。
