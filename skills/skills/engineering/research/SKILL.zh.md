---
name: research
description: 针对高可信度的权威来源调查问题，并将研究结果整理为 Markdown 文件保存到仓库中。在用户希望研究某个主题、收集文档或 API 资料，或希望将阅读调研工作委托给一个后台 agent 时使用。
---

启动一个**后台 agent** 来完成调研工作，这样你可以在它阅读的同时继续自己的工作。

它的任务是：

1. 针对该问题调查**权威来源**（官方文档、源代码、规范、官方一手 API），而不是关于它们的二手解读。每一项断言都要追溯到其所属的源。
2. 将调研结果写入单个 Markdown 文件，每个断言都注明来源。
3. 保存到仓库中已有的笔记位置；匹配现有的约定，如果没有约定，就放在一个合理的位置并说明放在哪里。
